# Kabbalistic Meditations

The letters of the day and the night, and how to practice them.

- **Today's letters** — the sun's letter by day, the moon's letter by night, and the
  day's holy name. The moon's position is computed live in the browser.
- **Practice** — how the daily practice works, the twelve letters with their signs,
  organs, and senses, and the holy names of the week.

Built with [Astro](https://astro.build), static output, deployed on GitHub Pages.

## Dev

```sh
npm install
npm run dev        # localhost:4321
npm run build      # production build → ./dist/
```

## Sources

Letter, sign, and organ correspondences follow Sefer Yetzirah, chapter 5.
The practice notes are the author's own experience, not official teaching.
